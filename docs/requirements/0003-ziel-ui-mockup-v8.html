Everything the workshop says to you is a question it holds out — a wait node of some run. Everything you say is an answer to one.   • State is shown, never restated. A state shows in the shape of the element itself — colour, placeholder, glyph — and is never repeated as a sentence. Text stands only where no element shows it.
  • Origin and provenance stand only where they deviate from the default ("chosen now", "set in the conversation", "group, 3 projects").
  • Explanations come on request — tooltip, "Technical", "Raw" — never inline.
  • Line rule. Framed is what lies on a living shelf and can be opened — the run row, the card, the stage. Ruled is the list of what is over — Recent runs, History. A room never mixes the two on one shelf.
  • One thing alive. On any screen exactly one element moves: the node where a hand is right now. Every other running run carries its blue still.
